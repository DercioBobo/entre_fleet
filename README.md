# Entre Fleet

Gestao de Frotas - Entretech

Standalone Frappe app for fleet management (vehicles, drivers, trips, fuel, maintenance,
documents, fines). Owns every doctype independently — no dependency on HRMS or ERPNext core.

## Installation

```bash
bench get-app entre_fleet <repo-url>
bench --site <site-name> install-app entre_fleet
```
